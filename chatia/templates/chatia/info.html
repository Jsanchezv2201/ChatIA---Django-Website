Resumen del funcionamiento general, estructura y créditos del proyecto.

Cómo funciona Chat con LLM y streaming en tiempo real

Los usuarios inician sesión, crean y gestionan conversaciones. Cada prompt se envía al servicio de LLM y la respuesta se muestra progresivamente mediante streaming (SSE), permitiendo ver la generación en tiempo real. Todas las conversaciones y mensajes se guardan en la base de datos para consultar el historial y exportarlo si se desea.

Estructura Arquitectura Django y CSS modular

La aplicación está organizada en capas: vistas y servicios que gestionan la lógica y la integración con el LLM, plantillas Django reutilizables y hojas de estilo modulares (00-base, 01-shell-nav, 02-layout-chat, ...). También hay endpoints HTMX/JSON y utilidades para exportación y streaming.

Créditos Juan Sánchez Vinuesa — Proyecto final (Servicios Telemáticos 2025/2026)

Desarrollado por Juan Sánchez Vinuesa como proyecto final para la asignatura Servicios Telemáticos (curso 2025/2026). Incluye chat con LLM, streaming de respuestas, exportación a Markdown y diseño pensado para despliegue en entornos tipo PythonAnywhere.
